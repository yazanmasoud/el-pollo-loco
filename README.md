# El Pollo Loco

A browser-based jump-and-run game built with JavaScript using object-oriented programming principles.

## Features

- Character movement and animations
- Jumping and enemy interactions
- Collision detection
- Collectible coins and bottles
- Health, coin, and bottle status bars
- Boss fight with boss health bar
- Throwable bottles with splash effects
- Sound effects and background music
- Mute and volume controls
- Game Over and You Win screens
- Restart and Home functionality
- Responsive controls for desktop, tablet, and mobile devices
- Touch controls for mobile and tablet
- Fullscreen support

## How to Run

1. Clone or download the repository.
2. Open the project in your code editor.
3. Start the project using a local web server.
4. Open the provided server address in your browser.
5. Click **Start Game** and enjoy!

## Technologies

- HTML5
- CSS3
- JavaScript
- Object-Oriented Programming (OOP)
- HTML Canvas

## Controls

### Desktop

- `Arrow Left / Arrow Right` – Move
- `Arrow Up / Space` – Jump
- `D` – Throw bottle

### Mobile / Tablet

- Touch controls for movement
- Touch button for jumping
- Touch button for throwing bottles
- Menu button for additional game options

## Project Structure

The game is structured using JavaScript classes and object-oriented programming principles.

Key components include:

- Character
- Enemies
- Boss
- Throwable Bottles
- Collision Manager
- World
- Audio Manager
- Status Bars
- Start and End Screens
